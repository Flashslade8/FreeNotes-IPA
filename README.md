# Free Notes

A free handwriting note-taking app for iPad and iPhone, built with SwiftUI and PencilKit.

<p align="center">
  <a href="https://flashslade8.github.io/Free-notes/">
    <img src="https://img.shields.io/badge/Install_on_iPad-Free_Notes-4f6bff?style=for-the-badge&logo=apple&logoColor=white" alt="Install Free Notes on iPad" height="48">
  </a>
</p>

Tap the button on your iPad. It opens the install page, where you tap **Install with SideStore** or **Install with AltStore**. That app signs Free Notes with your Apple ID and installs it.

**You need:** [SideStore](https://sidestore.io) or [AltStore](https://altstore.io) already set up on your device.

**Good to know:** apps installed with a free Apple ID expire after 7 days and need refreshing.

Prefer a file? Download [FreeNotes.ipa](https://github.com/Flashslade8/Free-notes/releases/download/latest/FreeNotes.ipa) and install it with Sideloadly.
